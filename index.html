操作使用指南

基础交互
鼠标悬停节点：显示自定义 Tooltip（支持 HTML）
双击元素：右侧打开属性编辑面板（实时渲染）
点击节点：选中；连续点击两节点自动连线
拖拽节点：自由移动位置
滚轮 / 拖拽画布：缩放与平移
属性编辑
可视化编辑：修改颜色、大小、文本等，实时生效
JSON 编辑：直接编辑 JSON 数据，实时同步到画布
标签偏移：X/Y 偏移量（可为负数），实时生效
背景图片：输入图片 URL，圆形裁剪填充节点
布局算法
数据流向布局：按连线方向左→右分层排列
层级树状布局：树形结构，根在上子在下
快捷创建 / 删除
双击空白：就地快捷创建新节点
选中后按 Delete 或 Backspace 删除
预设 & 右键
插入预设：从已保存的模板快速创建节点
右键节点：复制 / 导出配置 / 保存为预设
右键画布空白：粘贴已复制的节点
双向连线
双向连线：若两节点间有 A→B 和 B→A，连线自动弯曲避免重叠
导入 / 导出
数据 下拉：导入 / 导出 JSON 数据
导出图片 下拉：导出 PNG / SVG
视图
主题：深色 / 浅色切换
网格：画布网格线开关（导出时自动隐藏）
复制节点
导出节点配置
保存为预设
粘贴节点
编辑属性
直接编辑 JSON，实时生效
